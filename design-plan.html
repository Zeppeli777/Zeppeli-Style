不同作品的配色，怎样用在同一套组件里？

彩色漫画把绿配饰放在深紫上衣上；动画则把橄榄绿给了披风，深紫上衣配铜色装饰。可以借用这种换色方式：博客的铁球用较暗的铜绿，项目封面改用鲜绿，并把紫色从细节点缀扩展成整块底色。金黄留给螺旋、金牙或精选标签。

这些色值是界面设计取色。换色时保留球面刻纹、螺旋轨迹、方块节奏等轮廓。选中、错误和警告各自保留图标与文字，独立于封面配色。JoJo Wiki · 外观与配色对照

实施顺序与验收

  1. 定视觉。先敲定配色、图标在 16 / 24 像素下的轮廓、焦点环与静态纹样。文章主题默认素面；封面和项目精选区可单独开启装饰。
  2. 按页面实现 Vue 3 首版。用个人首页、中文长文、项目概览三页联调。基础层导出带前缀的 CSS 变量与 SVG，Vue 层提供 TypeScript 类型、插槽和事件。抽屉复用 Reka UI 的交互基础。
  3. 用真实内容验收。检查窄屏长标题、宽代码块、空数据、单点折线和进度边界。键盘可打开抽屉、用 Esc 关闭并回到触发项。减少动态效果时用静态球和文字提示状态。
  4. 验证复用。在一个独立 Vue 站点按需引入组件并覆盖主题色。组件样式限定在库的类名下。出现实际 React 项目后，共用变量、图形和样式，另写交互封装。
